Why it feels smoother

      
Constant optical mass. Every eye state — vertical pill, chunky circle, 2×2 grid, 3×3 matrix, dual bars, sideways pill, or chevron — is matched in solid ink area. Even blinks compress into a bold horizontal capsule rather than a thin hairline.

      
Multi-cell fission & fusion. Single eyes subdivide cleanly into 4-cell or 9-cell matrices and fuse back with staggered quintic timing and subtle left-to-right lead-follow.

      
Dual-rate springs. Eye saccades snap crisply across the curved 3D surface while body tilt follows on a softer, cushioned secondary spring.

      
Universal SVG silhouettes. Pass a preset name, a raw SVG d path, or a slotted <svg slot="shape"> element — soft-body harmonics and silhouette morphing work on all of them.

Single zero-dependency file. Works in plain HTML, React, Vue, Svelte, or anywhere Custom Elements run.

    

    

      

        
1. Include once & use anywhere


<script src="https://cdn.jsdelivr.net/gh/aphesist/orb2@main/orb-avatar.min.js"></script>

<orb-avatar shape="squircle" eye-shape="pill"
            color="#4fc9a8" mode="follow"></orb-avatar>

<!-- Asymmetric eyes + autonomous eye choreography -->
<orb-avatar shape="drop" eye-shape="circle wide"
            color="#6e5cf2" alive></orb-avatar>

      


      

        
2. Custom SVG silhouettes


<!-- Pass any SVG path directly -->
<orb-avatar shape="M0-92 C58-92 94-48 94 16 C94 72 54 96 0 96 C-54 96-94 72-94 16 C-94-48-58-92 0-92Z"></orb-avatar>

<!-- Or drop a standard <svg> inside -->
<orb-avatar reaction="compute" color="#f7a335">
  <svg slot="shape" viewBox="0 0 100 100">
    <path d="M50 4 L94 28 L94 72 L50 96 L6 72 L6 28 Z"/>
  </svg>
</orb-avatar>

      


      

        
3. Drive eye morphs & sequences from JS


const orb = document.querySelector('orb-avatar');

orb.setShape('squircle');     // morphs body silhouette
orb.morphEyes('grid');        // morphs eyes to 2x2 grid
orb.react('compute');         // switches reaction
orb.emote('shapeshift');      // pill → circle → grid → wide → pill

// Custom eye-shape & gaze choreography in one call:
orb.sequence([
  { eyes: 'pill',   gaze: [0, 6],    hold: 0.5 },
  { eyes: 'circle', gaze: [22, 12],  hold: 0.7 },
  { eyes: 'grid',   gaze: [-18, 4],  hold: 0.9 },
  { eyes: 'wide',   gaze: [16, -4],  hold: 0.8 },
  { eyes: 'pill',   gaze: [0, 6],    hold: 0.5 },
]);

      


      

        
4. Register reusable shapes & reactions


OrbAvatar.defineShape('shield',
  'M0 -95 L86 -62 L86 8 C86 58 46 88 0 98 C-46 88 -86 58 -86 8 L-86 -62 Z'
);

const { pairEyes } = OrbAvatar.shapes;
OrbAvatar.defineReaction('verify', {
  label: 'Verifying',
  face: () => pairEyes('grid', 'wide'),
  motion: t => ({ eyaw: .3 * Math.sin(t * 1.6), w: .85 })
});
